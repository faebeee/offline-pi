# web

The one UI of outpost: every screen of every module, as a single React
app. Core builds it into its image and serves it at `/`; the browser talks
only to core (one origin, no CORS, no ports).

- Vite + React 19 + TypeScript
- [TanStack Router](https://tanstack.com/router) with file routes
  (`src/routes/`, `src/routeTree.gen.ts` is generated by the Vite plugin or
  `npx tsr generate`)
- [TanStack Query](https://tanstack.com/query) through the hooks generated
  from core's OpenAPI document ([`@outpost/api-client`](../../packages/api-client/README.md))
- The Outpost design system ([`@outpost/ui`](../../packages/ui/README.md),
  [`DESIGN.md`](../../DESIGN.md)), bundled; no runtime network requests

## Layout

```
src/
  main.tsx              QueryClient, router
  routes/               one file per screen: / (home), /system, /maps,
                        /mesh, /mesh-map, /library
  features/<domain>/    components, hooks and CSS of one domain
  app/
    Screen.tsx          the frame: header (label, title, actions, theme
                        toggle), optional context line, content, module nav
    strip.tsx           shared status strip: useStripLink, useStripItems
    Nav.tsx             module nav from /api/modules
    realtime.ts         useSocket / useSocketEvent (Socket.IO namespaces)
    maplibre.ts         MapLibre with a local worker, pmtiles:// protocol
  ui/outpost.tsx        React wrappers: Icon, Badge, Banner, HoldButton, ...
  features/modules/     useModules, ModuleGate, ModuleSwitches
```

## A screen

```tsx
export const Route = createFileRoute("/radio")({ component: Radio });

function Radio() {
  const { data } = useRadioStatus();                  // generated hook
  useStripLink(data ? "ok" : "cau", data ? "RADIO · LINKED" : "RADIO · CONNECTING");
  useSocketEvent("/radio", "status", (s) => {/* update the Query cache */});
  return (
    <Screen module="radio" title="Radio">
      <ModuleGate id="radio">{/* the screen */}</ModuleGate>
    </Screen>
  );
}
```

- **Data** only from `@outpost/api-client`: hooks for REST, typed socket
  events for live updates (write them into the Query cache with the
  generated `get...QueryKey()`). Raw module files (map tiles, `.pmtiles`,
  kiwix articles) come from core's passthrough `/svc/<module>/`.
- **`ModuleGate`** renders the screen only while the module's container
  runs; otherwise it explains why and offers START.
- A new endpoint in core: `npm run api:gen` at the root, then use its hook.

## Development

```bash
npm run dev:core   # core (API, sockets, passthrough) on :8080
npm run dev:web    # this app on :5173, proxies /api, /socket.io, /svc, /ui to core
```

`CORE_URL` points the dev server at another core (e.g. the Pi:
`CORE_URL=http://raspberrypi.local:8080 npm run dev:web`).
