# zims.txt - the ZIM files this box downloads and serves.
#
# One entry per line: the ZIM file name WITHOUT the date suffix and ".zim",
# exactly as listed on https://download.kiwix.org/zim/ (or the "download"
# link on https://library.kiwix.org/). Examples:
#   wikipedia_en_medicine_maxi_2026-10.zim  ->  wikipedia_en_medicine_maxi
#   ifixit_en_all_2025-12.zim               ->  ifixit_en_all
# Many topics come in flavours: _maxi (with images), _nopic, _mini (intro
# only). Pick exactly the flavour you want.
#
# This file is baked into the container image. The container downloads
# every entry that isn't on disk yet each time it starts (resumable,
# checksum-verified) and serves them as soon as they're complete. After
# editing, apply it with `./start.sh` (rebuilds + restarts) or
# `./manage.sh sync`. Removing a line does not delete the file; use
# `./manage.sh prune` for that.
#
# Sizes are approximate (catalog of 2026-11).
