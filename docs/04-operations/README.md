# Operations

Once offline-pi is installed, most of the day-to-day work happens in the web
app: switching modules on and off, downloading maps and books, reading the
logs. A few things need a terminal on the Pi: restarting after a change,
updating to a new version, configuring the Meshtastic node, backing up and
uninstalling.

All commands on these pages run in the project folder (the Git clone), as
your normal user.

## Pages

- [Everyday commands](01-everyday-commands.md): `start.sh` and `manage.sh`,
  including every module command.
- [Updating](02-updating.md): installing a new version with `update.sh`,
  and going back.
- [Backup and restore](03-backup-and-restore.md): what to copy and how to
  set offline-pi up again on a new SD card.
- [Uninstall](04-uninstall.md): removing offline-pi, with or without its
  data.
- [Troubleshooting](05-troubleshooting.md): symptoms, causes and fixes.
