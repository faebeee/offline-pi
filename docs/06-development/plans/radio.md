# Plan: `apps/radio`, RTL-SDR receiver

## What it is

A web radio receiver on the Pi: anyone on the hotspot can listen to
broadcast and local radio traffic in the browser. In an outage the
relevant things to receive in Switzerland are:

- **Official broadcasts:** DAB+ and the remaining FM stations, including
  the federal emergency radio (IBBS) that authorities use in a crisis.
  Frequencies are regional: look them up for your area (BABS / admin.ch)
  and enter them as presets. Do not hardcode them in the repo.
- **PMR446:** licence-free walkie-talkies, what neighbours and helpers will
  actually use. 16 channels, 446.00625 to 446.19375 MHz, 12.5 kHz steps.
- **Amateur radio** 2 m / 70 cm repeaters, if there's local activity.
- Later: weather satellite images (Meteor-M LRPT). Note: the NOAA APT
  satellites were retired in 2025, so older tutorials are out of date.

Receive only. Nothing here transmits.

One dongle tunes one band (about 2.4 MHz wide) at a time, so all listeners
share one tuning. The UI must make that obvious.

## Hardware

- **RTL-SDR Blog V4** (or V3). The V4 needs the `rtl-sdr-blog` driver fork;
  the stock Debian `librtlsdr` does not support it. Whatever image we use
  must have a driver that supports the dongle.
- Antenna: the telescopic dipole from the kit is enough for FM/DAB+/PMR
  nearby; a vertical for 446 MHz improves PMR range.
- Powered USB hub (the dongle draws about 300 mA and gets warm).

## Architecture (decided in R0)

**Option A, preferred: wrap OpenWebRX+** (`slechev/openwebrxplus`,
pinned tag). Mature web SDR: waterfall, many listeners, FM/NFM/AM, digital
modes, bookmarks, SatDump-based satellite decoding. The app then is mostly
our install/start/uninstall/manage scripts, host setup and a preset file.
Check in R0: RTL-SDR V4 support in the image, CPU load on the Pi, whether
DAB+ works (if not, add `welle-cli` as a second mode, see option B).

**Option B, fallback: own small service.** Python or Node backend that
spawns `rtl_fm | ffmpeg` (FM/NFM to MP3) or `welle-cli -w` (DAB+), fans the
audio stream out to all HTTP listeners, and serves a simple preset UI.
Simpler UI, much less CPU, more code to own. Choose B if A is too heavy for
the Pi or lacks a must-have.

Either way:

- **Host setup** (done by `install.sh` with `sudo`, reversed by
  `uninstall.sh`): `/etc/modprobe.d/outpost-radio.conf` blacklisting
  `dvb_usb_rtl28xxu` (otherwise the kernel's DVB-T driver grabs the
  dongle), unload it if loaded, and a udev rule
  `/etc/udev/rules.d/60-outpost-radio.rules` giving `plugdev` access to
  the dongle's USB IDs.
- **Container:** USB passthrough of `/dev/bus/usb` (OpenWebRX needs the bus,
  not a single node), `group_add: [keep-groups]`.
- **Presets:** `${DATA_DIR}/presets.json` (or OpenWebRX bookmarks),
  seeded with PMR446 ch 1 to 16 and empty placeholders for local
  FM/DAB+/IBBS that `install.sh` asks the user to fill in.
- **Recordings** (R3): `${RECORDINGS_DIR}`, relocatable per AGENTS.md.
  This is the one directory that can grow, so it gets its own variable and
  a size cap.

## `.env` variables

| Var | Default | Notes |
|---|---|---|
| `PORT` | `8085` | |
| `BIND_ADDRESS` | `0.0.0.0` | |
| `DATA_DIR` | `./data` | Config, presets, OpenWebRX settings |
| `RECORDINGS_DIR` | `./recordings` | Can grow; point at SSD once power is fixed |
| `RECORDINGS_MAX_GB` | `5` | Oldest deleted first, only recordings |
| `ADMIN_USER` / `ADMIN_PASSWORD` | | Option A: OpenWebRX settings login; generated by install.sh |

## Sessions

### R0: Host prep and spike
**Goal:** dongle works on the Pi in a container, and option A or B is chosen.

- [ ] Blacklist `dvb_usb_rtl28xxu`, udev rule, check with `rtl_test` in a
      throwaway container that has a V4-capable driver.
- [ ] Run OpenWebRX+ pinned image with `/dev/bus/usb` passed through.
      Measure: CPU and temperature (use `apps/monitor`) with 1 and 3
      listeners on FM and NFM; does DAB+ work; does it survive unplugging
      the dongle.
- [ ] Write the decision (A or B) and the measurements into this file, and
      adjust R1 to R4 if B.

**Done when:** you heard a local FM/DAB+ station and a PMR446 radio
(use your own walkie-talkie) through the browser on a phone.

### R1: Scaffold
- [ ] `apps/radio/` per AGENTS.md; `lib/host.sh` with `radio_host_install`
      / `radio_host_remove` (module blacklist, udev, `udevadm trigger`),
      checks `plugdev` membership.
- [ ] Compose with the chosen image (A: upstream, pinned; B: `build: .`),
      `restart: always`, `CMD-SHELL` healthcheck.
- [ ] `install.sh` generates the admin password (A) and prints it once.
- [ ] `uninstall.sh` from the template plus a host-cleanup hook.

**Done when:** `./install.sh` on a fresh Pi with the dongle plugged in ends
with a working receiver on 8085, and `./uninstall.sh` removes the
blacklist and udev rule.

### R2: Presets for an emergency
- [ ] Seed PMR446 channels and amateur 2 m/70 cm calling frequencies.
- [ ] `install.sh` / `manage.sh preset add <name> <freq> <mode>` for local
      FM, DAB+ and IBBS stations.
- [ ] A "listen to official broadcast" one-tap preset on top of the UI
      (A: default profile/bookmark; B: first button).
- [ ] Short German help page in the portal: what you can hear, that it's
      receive only, PMR446 channel table.

**Done when:** a non-technical person on the hotspot finds and plays the
emergency broadcast in under a minute.

### R3: Recording (optional)
- [ ] `manage.sh record <preset> <minutes>` and an optional schedule
      (systemd user timer) for e.g. hourly news.
- [ ] Size cap enforcement, recordings listed and playable in the UI.

**Done when:** a scheduled recording appears and old ones are pruned at the
cap without touching other files.

### R4: Satellites, portal, docs
- [ ] Optional: Meteor-M LRPT images via SatDump (option A has this
      built in), needs a V-dipole or QFH antenna outdoors.
- [ ] Add radio to the portal's default `apps.json`.
- [ ] `README.md` (hardware, host changes made, presets, the "one tuning
      for everyone" limitation, uninstall), root `README.md` row.

**Done when:** a fresh clone only needs `./install.sh`, and the portal
shows the radio tile.
